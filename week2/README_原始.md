舵机控制原理:
舵机的转动角度由高电平时间决定。
固有的高电平时间由舵机自身决定（以 SG90 为例）：
$0.5\text{ ms}$ 对应 $0^\circ$
$2.5\text{ ms}$ 对应 $180^\circ$
操控参数：$f_{clk}$、$PSC$、$ARR$、$CCR$
公式推导
定时器频率：
$$f_{TIM} = \frac{f_{clk}}{(PSC + 1)(ARR + 1)}$$
周期：
$$T = \frac{1}{f_{TIM}}$$
占空比：
$$\text{占空比} = \frac{CCR}{ARR + 1}$$
高电平时间（代入化简）：
$$t_{\text{高电平}} = T \cdot \frac{CCR}{ARR + 1} = \frac{CCR \cdot (PSC + 1)}{f_{clk}}$$

舵机的驱动使用psc = 71;arr = 19999;fclk = 72mhz,这样实现了舵机驱动的50hz;

然后用__HAL_TIM_SET_COMPARE把ccr传入对应的引脚即可
