## 任务一：非阻塞按键消抖

利用硬件定时器周期性触发中断，每隔固定时间 $t$ 进入一次中断回调函数。定时周期计算公式如下：

$$f_{TIM} = \frac{f_{clk}}{(PSC + 1)(ARR + 1)}$$

$$t = \frac{1}{f_{TIM}}$$

* **参数配置**：系统时钟 $f_{clk} = 72\text{ MHz}$，取 $PSC = 71$，$ARR = 9999$，得到中断周期：
  $$t = 0.01\text{ s} = 10\text{ ms}$$
* **消抖逻辑**：每进入一次中断回调函数，计时变量加 $1$，从而忽略两次计时采样间隔内的按键电平抖动，实现非阻塞式消抖。

## 任务二：PWM 呼吸灯与舵机驱动

本任务共使用三个定时器，分别负责不同功能：
* **`TIM2`**：用于非阻塞式计时
* **`TIM3`**：用于 PWM 驱动外接 LED 呼吸灯
* **`TIM4`**：用于 PWM 驱动舵机

呼吸灯与舵机均采用定时器 PWM 方式控制，以下以舵机为例说明控制原理与公式推导。

### 1. 舵机控制原理
舵机的转动角度由单个 PWM 周期内的**高电平持续时间**决定，具体对应关系由舵机硬件特性决定（以 SG90 舵机为例）：
* $0.5\text{ ms}$ 高电平 $\rightarrow 0^\circ$
* $2.5\text{ ms}$ 高电平 $\rightarrow 180^\circ$

### 2. 公式推导
涉及的核心操控参数为：$f_{clk}$、$PSC$、$ARR$、$CCR$。

* **定时器频率**：
  $$f_{TIM} = \frac{f_{clk}}{(PSC + 1)(ARR + 1)}$$
* **PWM 周期**：
  $$T = \frac{1}{f_{TIM}}$$
* **占空比**：
  $$\text{占空比} = \frac{CCR}{ARR + 1}$$
* **高电平时间**（代入化简）：
  $$t_{\text{高电平}} = T \cdot \frac{CCR}{ARR + 1} = \frac{CCR \cdot (PSC + 1)}{f_{clk}}$$

### 3. 参数配置与角度换算
* **舵机参数**：系统时钟 $f_{clk} = 72\text{ MHz}$，设置 $PSC = 71$，$ARR = 19999$，实现 $50\text{ Hz}$ 的舵机驱动频率。
* **旋转角度与 `CCR` 的换算关系**：
  ```c
  uint32_t servo_ccr = (uint32_t)((angle / 90.0f + 0.5f) * 1000.0f);
  ```
* **输出控制**：调用 `__HAL_TIM_SET_COMPARE()` 函数，将计算出的 `CCR` 值写入对应定时器通道，即可在目标引脚输出相应脉宽的 PWM 信号控制舵机转动。

## 任务三：ADC1 采集电位器电压

* **量程说明**：STM32F103C8T6 内置 12 位 ADC，共有 $2^{12} = 4096$ 个量化等级，因此采集到的数字量范围为：
  $$ADC \in [0, 4095]$$
* **电压换算公式**：
  $$V_{\text{out}} = \frac{ADC}{4095.0} \times 3.3\text{ V}$$
